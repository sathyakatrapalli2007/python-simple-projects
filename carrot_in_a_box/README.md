# 🥕 Carrot in a Box

A fun little command-line bluffing game built in Python, based on the classic **Carrot in a Box** game. This project was created as part of my practice with *The Big Book of Small Python Projects* by Al Sweigart.

## 🎮 About the Game

Carrot in a Box is a simple game of luck, bluffing, and a little bit of psychological warfare. Two players each have a box, but only one box contains a carrot. The first player secretly checks their box and then gets to decide whether to keep it or swap boxes with the second player.

The second player must then decide whether to accept the swap or keep their original box, without knowing where the carrot actually is. Once both players have made their decisions, the boxes are revealed to determine who gets the carrot!

It's a tiny game, but there's a surprising amount of fun in trying to outsmart the other player.

## ✨ Features

- 🥕 Randomly placed carrot
- 📦 Two-player gameplay
- 🔄 Box swapping mechanic
- 🎭 Bluffing and decision-making
- ⌨️ Interactive command-line prompts
- 🎲 Randomized game outcomes
- 🏆 Winner announcement

## ▶️ How to Run

Run the program from the terminal:

```bash
python main.py
```

Follow the prompts to play the game and make your decisions.
