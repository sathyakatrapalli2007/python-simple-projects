# 🎂 Birthday Paradox (Python)

A simulation of the famous **Birthday Paradox** that demonstrates how surprisingly likely it is for two people in a group to share the same birthday.

---

## 🚀 Features

* 🎂 Generates random birthdays
* 🔍 Detects duplicate birthdays in a group
* 📊 Runs 100,000 simulations
* 📈 Estimates the probability of a shared birthday

---

## 🧠 How It Works

* Generates random birthdays for a specified number of people
* Checks whether any two birthdays match
* Repeats the experiment 100,000 times
* Calculates the percentage of simulations containing at least one matching birthday

---

## ▶️ Usage

```bash
python main.py
```
